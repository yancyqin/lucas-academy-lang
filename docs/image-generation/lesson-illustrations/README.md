# 成语与经文插图

本组图片使用内置 `image_gen`，每张独立生成。完整提示词在 [prompts.json](prompts.json)，生成来源、原始 PNG 的 SHA-256、最终 WebP 的尺寸、字节数和 SHA-256 在 [generated-sources.json](generated-sources.json)。最终图片保存在 `public/images/lessons/`，由 `public/lessons/illustrations.js` 记录资源和稳定的课文单元绑定。

范围：

- 两辑共 20 个成语，各一张故事场景图，绑定成语名称单元。
- 两辑搭配的 28 节经文，按节配图。
- 《爱的篇章》13 节与《种子与好土》9 节，按节配图。
- 哥林多前书 13:12 同时用于《爱的篇章》和第一辑的「盲人摸象」，共用 `partial-seeing`。共 69 张图，70 处绑定。

图中没有课文字幕，文字仍由可选择、可朗读的网页呈现。风格包括水彩、水墨、版画、剪纸、毡布拼贴、黏土场景等。现代生活场景和象征性构图帮助思想经文，不作为经文中发生过的事件。例如哥林多前书 13 章用耐心等候、照顾别人和共同成长的场景；马可福音 4 章直接画湖边讲道、撒种、不同土壤及收成。希伯来书 12:2 使用远景背负十字架，不展示血腥细节。

交付为宽 960 像素的 WebP；缩小和编码保留完整构图与原始宽高比。阅读页延迟加载，逐句学习页即时加载；宽高属性为图片预留空间。切换语言会改变图片的描述，切换单元会改变对应图片。失败的图片隐藏，文字和原有学习操作仍可使用。

`npm run validate` 校验绑定目标、双语描述、文件存在、尺寸元数据和字节哈希。最终浏览器核验记录在 [qa.json](qa.json)。
