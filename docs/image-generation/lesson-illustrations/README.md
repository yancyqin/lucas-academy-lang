# 成语与经文插图

本组图片使用内置 `image_gen`，每张独立生成。完整提示词在 [prompts.json](prompts.json)，生成来源、原始 PNG 的 SHA-256、最终 WebP 的尺寸、字节数和 SHA-256 在 [generated-sources.json](generated-sources.json)。最终图片保存在 `public/images/lessons/`，由 `public/lessons/illustrations.js` 记录资源和稳定的课文单元绑定。

范围：

- 第一辑 10 个成语、第二辑 5 个成语，各一张故事场景图，绑定成语名称单元。
- 两辑搭配的经文中 15 节配图。
- 《种子与好土》9 节，按节配图。共 39 张图，39 处绑定。

2026-10-09 审图后删去 30 张：《爱的篇章》13 节的全部配图（含与「盲人摸象」共用的哥林多前书 13:12），以及画抽象概念、效果不好的另外 17 张（成语口蜜腹剑、以德报怨、近朱者赤、知足常乐、入乡随俗；经文马太福音 4:17、5:34、5:37、5:44、5:45、15:8，约翰一书 1:6、4:19，哥林多后书 3:18，以赛亚书 43:18，马太福音 17:20 芥菜种，雅各书 5:7 农夫等候）。这些单元不再显示插图。

图中没有课文字幕，文字仍由可选择、可朗读的网页呈现。风格包括水彩、水墨、版画、剪纸、毡布拼贴、黏土场景等。现代生活场景和象征性构图帮助思想经文，不作为经文中发生过的事件。例如马可福音 4 章直接画湖边讲道、撒种、不同土壤及收成。希伯来书 12:2 使用远景背负十字架，不展示血腥细节。

交付为宽 960 像素的 WebP；缩小和编码保留完整构图与原始宽高比。阅读页和逐句学习页的插图默认收起，点「显示图」才展开并加载；宽高属性为图片预留空间。切换语言会改变图片的描述，切换单元会改变对应图片。失败的图片隐藏，文字和原有学习操作仍可使用。

`npm run validate` 校验绑定目标、双语描述、文件存在、尺寸元数据和字节哈希。最终浏览器核验记录在 [qa.json](qa.json)。
