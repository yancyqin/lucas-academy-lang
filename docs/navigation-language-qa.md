# 课程导航与界面语言核验

2026-10-09。浏览器直接加载本分支的 `public/` 文件；《爱的篇章》的受许可英文经文通过线上只读 API 获取，仅留在核验进程内存。

Chromium 与 WebKit 均核验：

- 首页课程表链接进入 `/class`，课程链接返回对应课文；阅读顺序在刷新和两页间保持。
- 课程页只保留周选择、课程卡片和作业。旧 `g` 参数、旧年级存储不影响当前小组；周链接规范为 `/class?w=1`。不存在的周显示提示并打开本周。
- 使用浏览器临时课表验证第二周切换、地址栏、指定小段链接、双语作业和没有课程的提示；仓库课表仍只有原来的第 1 周。
- 成语、故事、独立圣经课文和诗歌课文的两种阅读顺序。英文在前对应中文操作界面，中文在前对应英文操作界面。
- 阅读页和逐句弹窗的遮住与揭示按钮指向后读语言；默写隐藏先读语言。逐句弹窗的阅读顺序、换角色提示和语言切换一致。
- 已打开的词语面板和生词本随界面语言更新。
- 首页在 320、390、700、768、1024、1440 像素宽度下没有横向溢出，顶部链接和按钮至少 44 像素高；两种语言的逐句弹窗检查手机布局，标题可换行，返回按钮保持可见。

两种浏览器的运行错误和缺失本地资源均为 0。`npm run validate` 和 `git diff --check` 通过，包括现有配音清单以及 69 张插图、70 处绑定的校验。
